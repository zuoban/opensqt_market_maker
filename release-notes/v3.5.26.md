# v3.5.26

本次更新精简做市架构并移除量能异常主动风控，优化重启持仓恢复与开单对齐逻辑，改进后台标签页价格标题刷新，并全面重构监控面板视觉层次与移动端体验。

## 架构重构与重要变更 (Breaking Changes)

- 移除量能异常主动风控：彻底移除 `risk_control` 配置项、`RiskMonitor` 后台协程、交易门禁中的量能风控拦截以及监控面板中的主动风控展示。保证金率硬守卫（Margin Guard）与其它核心健康检查保持不变。环境变量 `OPENSQT_RISK_CONTROL_*` 已失效。

## 交易与仓位优化

- 重启仓位与买格恢复：已有仓位按 min(当前网格, 持仓均价) 向下对齐买格恢复槽位，卖单挂槽位价加一格；普通买单统一从当前格下一格开始挂单，当前格仅在确认跳格漏买时作为合并父格下单，避免同价重启时贴盘重复加仓。

## 监控面板与视觉升级

- 后台标签实时刷新：收到快照推送时立即写入 `document.title`，即使浏览器标签处于非活跃后台状态也能持续更新最新价格与交易对。
- 视觉质感与主题精修：
  - 增强浅色与深色主题的对比度和质感，优化品牌标识在浅色主题下的立体光泽与渐变质感。
  - KPI 核心指标卡片采用弹性对齐布局，统一卡片高度与内边距，提升各屏幕下的整齐度。
  - 网格槽位状态胶囊增加微光层次感（活跃、持仓、预警、高亮），成交明细表格中的买卖方向增加圆角胶囊与微阴影，提升辨识度。
  - 桌面端状态栏与执行指标支持粘性停靠（`position: sticky`），便于长页面滚动时保持核心指标可见。
  - 优化移动端顶栏平铺吸顶与安全区域边距（Safe Area Insets），优化保证金容量条与底部导航项的触控微交互。

## 使用与边界

- 若您此前在 `config.yaml` 或环境变量中配置了 `risk_control`，更新后将被自动忽略，无需手动迁移。升级时保留自己的配置及环境变量；发行包中的 `config.yaml` 仍由模板生成，不包含真实密钥。
- 提供 Linux amd64、Windows amd64、MacOS arm64 发行包及 SHA256 校验文件。
- Docker 支持 linux/amd64 与 linux/arm64。

Docker 镜像：`ghcr.io/zuoban/opensqt_market_maker:v3.5.26`（对应本次版本）及 `latest`。
