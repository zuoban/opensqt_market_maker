# v3.5.25

本次更新监控面板标题展示，并推进成交账本离线原型；沿用现有配置。

## 改进

- 监控面板浏览器标题实时显示最新价与交易对，例如 `108.24 | SOLUSDC`；缺少有效行情时保持默认标题。
- 成交账本离线原型降低启动扫描分配，精确重试命中后回滚空事务，不再同步写盘。
- 增加离线存储健康门禁 `GuardedSlots`：Health 不等待数据库锁，超时或 I/O 故障锁存停单。测试中已接通真实执行器，故障后拦截新单，保护性撤单与 UNKNOWN 收敛仍可用。
- 补充旧终态修正在新订单绑定后崩溃的恢复场景，以及部署盘一键离线验收脚本。

## 清理

- 从版本库移除仅供本机使用的直播页和音频，并忽略 Playwright 抓取目录。

## 使用与边界

- 无新增必填配置。升级时保留自己的配置及环境变量；发行包中的 config.yaml 仍由模板生成，不包含真实密钥。
- 账本持久化仍为离线原型，未接入生产启动恢复或交易协调器；本次不提供跨重启精确恢复。
- 完整成交去重与终态历史仍保留在内存中，长期历史增长问题尚未解决。
- 提供 Linux amd64、Windows amd64、MacOS arm64 发行包及 SHA256 校验文件。Docker 支持 linux/amd64 与 linux/arm64。

Docker 镜像：`ghcr.io/zuoban/opensqt_market_maker:v3.5.25`（对应本次版本）及 `latest`。
