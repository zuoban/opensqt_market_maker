# v3.5.24

本次为 Go 做市程序的性能与发布维护更新，沿用现有配置。

## 改进

- 每轮调整只提交一个批次，随后使用最新盘口重新规划，优先处理卖单，缩短大量补单时的等待。
- 订单结果确认期间释放槽位提交锁；同一订单身份的重试重新经过限流、健康与盘口检查，保留结果不确定订单的原身份。
- 减少成交回调的临时分配，复用最近 20 条成交记录缓冲区，并优化槽位遍历。
- 控制台与文件日志采用有界异步队列，增加队列丢弃计数；面板无人访问时暂停高频仓位快照刷新，并支持 WebSocket 压缩。
- 对账中的持仓与挂单查询并行执行，补充调度及对向补单等待指标。

## 发布修复

- 构建环境升级为 Go 1.27.1，修复旧标准库中的已知漏洞，并将主程序漏洞扫描加入发布检查。
- 本地打包严格校验包名版本与程序版本一致；Windows ZIP 正确保存中文路径的 UTF-8 编码标记。
- Docker 使用原生交叉编译，并按 Go 版本、构建架构和目标架构隔离编译缓存，避免双架构构建复用不兼容的索引缓存。
- 提供 Linux amd64、Windows amd64、MacOS arm64 发行包及 SHA256 校验文件。Docker 支持 linux/amd64 与 linux/arm64。

## 使用与边界

- 无新增必填配置。升级时保留自己的配置及环境变量；发行包中的 config.yaml 仍由模板生成，不包含真实密钥。
- 本次降低临时分配和等待开销；完整成交去重与终态历史仍保留在内存中，长期历史增长问题尚未解决。
- 账本持久化仍为离线原型，未接入生产启动恢复；本次不提供跨重启精确恢复或 Rust 运行版本。
- 性能数据来自离线回放与本机基准，不代表实盘延迟承诺。

Docker 镜像：`ghcr.io/zuoban/opensqt_market_maker:v3.5.24`（对应本次版本）及 `latest`。
